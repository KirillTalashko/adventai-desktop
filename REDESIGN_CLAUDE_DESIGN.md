# Мета-промт: редизайн AdventAI Desktop в стиле **Claude Design** (бумага + терракота)

> Инструкция самому себе (Claude Code) для **полного** редизайна UI Compose Desktop.
> Цель — воспроизвести ощущение продукта **claude.ai**: тёплая «бумага», спокойный воздух,
> характерный терракотовый акцент, редакторская типографика с засечками в заголовках.
> Это **не** копирование Android-версии и **не** нынешний серо-синий «Claude Code» —
> предыдущий бриф `DESIGN_BRIEF.md` заменяется этим для визуального слоя.

---

## 0. Роль и режим работы

Ты — продуктовый дизайнер-инженер, переносящий язык claude.ai на **Compose Multiplatform Desktop 1.7.3 + Material 3**.
Работаешь по слоям: сначала токены (`Theme.kt`, новый `Type.kt`, `Dimens.kt`/`Radii`), потом экран за экраном.
Каждый шаг — компилируемый (`gradlew compileKotlin`), UI-правки проверяются харнессом/чистым стартом
(GUI-смоук в этой среде невозможен — см. память проекта). Границы архитектуры не трогаем:
UI знает только про `ChatState`, домен — про порты. Меняем **вид**, не логику.

---

## 1. Дух (что мы копируем у Claude)

1. **Бумага, не экран.** Тёплый кремовый фон вместо холодного белого. Ощущение страницы, а не приложения.
2. **Плоскость + волосяные границы.** Никаких drop-shadow. Разделение — тонкой линией `1.dp` тёплого серо-бежевого и сменой тона поверхности. `tonalElevation = 0.dp` везде.
3. **Один тёплый акцент.** Терракота/глина — только для активного, выбранного, ссылок и бренд-марки. Всё остальное — оттенки чернил на бумаге.
4. **Редакторская типографика.** Крупные заголовки-приветствия с засечками (serif), спокойный sans в теле, mono для токенов/кода.
5. **Много воздуха.** Крупные внутренние отступы, широкие «поля страницы», центрированная колонка чтения ~720–760.dp max-width в ленте.
6. **Скругления мягкие и щедрые.** Композер и карточки 16–20, пилюли — полностью круглые.
7. **Движение сдержанное.** Плавный hover поверхностей, мягкий автоскролл, дышащий индикатор набора. Никаких резких теней/цветовых вспышек.

## 3. Типографика (новый файл `ui/Type.kt`)

Бренд-шрифты claude.ai (Styrene, Tiempos/Copernicus) не под свободной лицензией — **не встраиваем**. Берём близкие OFL-аналоги, кладём `.ttf` в `src/main/resources/fonts/`, грузим через `Font(resource = "fonts/…")` в `FontFamily`.

- **Serif (заголовки, приветствие «Добрый день», пустое состояние):** `Newsreader` или `Source Serif 4` (OFL). Именно засечки задают «редакторское» ощущение Claude.
- **Sans (тело, UI, кнопки, списки):** `Inter` (OFL). Ровный, спокойный.
- **Mono (чипы токенов, код, id):** оставить текущий/`JetBrains Mono`.

Задать `Typography` в Material 3:
- `displaySmall`/`headlineMedium` → serif, крупный, `letterSpacing` слегка отрицательный (‑0.5), для приветствия и пустого состояния.
- `titleMedium` → serif или полужирный sans, заголовки диалогов/секций.
- `bodyLarge`/`bodyMedium` → Inter, высота строки 1.5 для читаемости длинных ответов агента.
- `labelLarge` → Inter medium, кнопки/чипы.
Прокинуть `typography = AppTypography` в `MaterialTheme` внутри `AdventTheme`.

## 4. Форма, отступы, движение

- **Radii (`Dimens.kt`):** оставить шкалу, сместить к щедрым значениям Claude: xs=8 (чипы), sm=12 (кнопки/айтемы), md=14 (карточки), lg=18 (бабл сообщения, карточки памяти/RAG), xl=24 (композер, онбординг). Композер — самый скруглённый элемент.
- **Отступы:** ввести шкалу 4/8/12/16/24/32. Ленту сообщений держать в центрированной колонке `widthIn(max = 740.dp)` с крупными боковыми полями. Сайдбар ~272.dp.
- **Границы вместо теней:** карточки = `surface` + `Modifier.border(1.dp, outlineVariant, RoundedCornerShape(Radii.lg))`. Тени (`elevation`, `shadow`) не использовать.
- **Клики:** только `Surface(onClick=…)` — ripple обрезается по скруглению (правило проекта). Ховер айтемов сайдбара/диалогов — плавная смена `surfaceVariant`.
- **Движение:** `animateColorAsState` на ховер/выбор; автоскролл ленты плавный; `TypingRow` — три пульсирующие точки терракотой; спиннер отправки — тонкий.

## 5. Экран за экраном (реальные композаблы `ui/App.kt`)

### `Sidebar` (+ `AccountSwitcher`, `SidebarButton`)
- Фон `#F0EEE6`, без границы-тени, только волосяная правая линия `outline`.
- Верх: бренд-марка (скруглённый квадрат) + «AdventAI / Визовый специалист» serif-подзаголовком.
- **«+ Новая сессия»** — заметная, но не кричащая: пилюля с тонкой границей `outline`, текст чернилами, иконка `Add` линейная. При ховере — заливка `surface`.
- Секция «Диалоги»: айтемы со скруглением sm; активный — тёплая заливка `secondaryContainer` + **левая акцентная полоска терракотой 3.dp** (не рамка вокруг). ✕ (`DeleteOutline`) появляется на ховере, приглушённый.
- Низ: «Память» и «Настройки» (`Settings`) линейными иконками, приглушённый текст.
- `AccountSwitcher` — компактная строка-пилюля с аватаром-инициалом на бумаге.

### `ChatPane` + `EmptyState`
- Верх — тонкий заголовок активного диалога serif-ом, под ним волосяная линия.
- `EmptyState`: по центру крупное serif-приветствие («Чем помочь с визой?»), под ним 3–4 **чипа-примера** (пилюли `outline`, ховер `surface`) — как стартовые подсказки claude.ai. Без иллюстраций-картинок, только текст и воздух.
- Лента: центрированная колонка ≤740.dp.

### `MessageView` / `TokenLine` / `ChecklistView` / `TypingRow`
- **Пользователь:** мягкая «пилюля» справа, заливка `surfaceVariant` (`#F0EEE6`), скругление lg, без границы.
- **Агент:** без пузыря — просто текст на бумаге слева, ширина колонки, высота строки 1.5. Под ответом — `TokenLine` чипом mono, приглушённый: `↑prompt ↓completion · Σtotal`.
- **`ChecklistView`:** карточка `surface` + граница `outlineVariant`, скругление lg. Каждая строка: линейная иконка статуса + текст + точка-бейдж цвета `StatusColors`. Статусы читаются с легендой.
- **`TypingRow`:** три точки терракотой, дышат.

### `Composer` (+ `SendButton`, `IconActionButton`, `DropdownChip`)
- Главный элемент. Скруглённое поле xl (24), `surface`, граница `outline`, при фокусе граница акцентом терракота 1.5.dp.
- Плейсхолдер «Спросите визового специалиста…» приглушённый.
- Нижняя панель: `DropdownChip` модели и режима памяти — пилюли `outline` с `KeyboardArrowDown`; счётчик токенов сессии mono; справа круглая **`SendButton`** — заливка `primary` (тёмные чернила), иконка `ArrowUpward` белая; в состоянии ответа — тонкий спиннер. Enter — отправка, Shift+Enter — перенос.
- `IconActionButton` — линейные иконки, круглый ховер `surfaceVariant`.

### Диалоги (`Dialogs.kt`, `RagDialog`, `McpToolsDialog`, `ConnectorsDialog`, `LocalLlmDialog`, `ProfileForm`, `TaskPanel`, `Onboarding`)
- Единый шаблон окна-диалога: `surface`, скругление xl, волосяная граница, крупный serif-заголовок, тело со шкалой отступов 16/24, кнопки-пилюли (primary = тёмная заливка, secondary = граница).
- **Карточки результатов** (`ResultCard`, `RagAnswerCard`, `RagEvidence`, `CitationEvalRow`, `LocalLlmResultCard`, `OptRunCard`, `RagVsCard`, таблицы `RagComparisonTable`/`GoldRetrievalView`): единый паттерн «бумажная карточка» — `surface` + `outlineVariant` + скругление md/lg, заголовок-метка приглушённый, моноширинные числа/токены/tok-s. Таблицы — зебра тёплым `outlineVariant`, без вертикальных линий.
- Тумблеры (`ConnectorToggleRow`) и строки скиллов (`InstalledSkillRow`) — акцент терракота во включённом состоянии.
- `Onboarding` — карта xl-скругления, serif-заголовок, спокойные шаги.

### Тёмная тема
- Переключение как есть (`AdventTheme(dark=…)`), но по новой тёплой тёмной палитре (см. §2). Проверить контраст терракоты и статусов на `#22211E`.

## 6. Правила Compose Desktop (грабли)

- Всё через `MaterialTheme.colorScheme` — не хардкодить hex в композаблах (кроме `AppColors`/`StatusColors`).
- Границы, а не `elevation`/`shadow`; `tonalElevation = 0.dp`.
- Кликабельность — `Surface(onClick=…)`, не `Modifier.clickable` на `Surface`.
- Шрифты — из `resources/fonts`, грузить один раз в `Type.kt`; проверить, что `.ttf` попадают в дистрибутив (`compose.resources`).
- JVM-target 21; публичный класс не светит `internal`-тип в конструкторе.
- Ничего из HTTP/Ktor/файлов в `ui` — только через `ChatState`.

---

## 7. Границы (что НЕ делаем)

- Не менять доменную логику, память, RAG-пайплайн, порты — только визуальный слой и state-holder при необходимости.
- Не тащить бренд-синий `#2F6BED` в интерфейс как акцент (только опционально в самой иконке-логотипе).
- Не добавлять теней, градиентов-«стекла», неоновых свечений — это не Claude.
- Не встраивать несвободные шрифты (Styrene/Tiempos) — только OFL-аналоги.
- Не ломать доступность ради эстетики: контраст — жёсткое требование.

## 8. Порядок исполнения (чек-лист)

1. `Theme.kt` — новые Light/Dark `colorScheme` + тёплые `StatusColors`; прокинуть `typography`.
2. `Type.kt` (новый) + `resources/fonts/*.ttf` — Newsreader/Source Serif + Inter; собрать `Typography`.
3. `Dimens.kt`/`Radii` — щедрые радиусы + шкала отступов.
4. Каркас: `App` → `Sidebar` → `ChatPane`/`EmptyState` → `Composer` → `MessageView`/`ChecklistView`.
5. Диалоги и карточки результатов — единый «бумажный» паттерн.
6. Тёмная тема — сверка контраста.
7. Компиляция + чистый старт + харнесс; визуальная сверка по разделу §5.

**Критерий готовности:** экран рядом со скриншотом claude.ai читается как «тот же язык» — тёплая бумага, терракотовый акцент, засечки в заголовках, плоскость с волосяными границами, воздух в ленте.
