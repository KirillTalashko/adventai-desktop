# Индия — электронная виза (e-Visa)

> Справочный материал для консультаций. Сборы и правила меняются — сверяйте на официальном портале e-Visa
> Индии. Волатильные факты сверены по веб-источникам на июль 2026.

## Визовый режим для граждан РФ

Для туризма гражданам РФ доступна **электронная туристическая виза (e-Tourist Visa)**. С **1 января 2026**
консульский сбор за **30-дневную** электронную турвизу для граждан РФ **отменён (бесплатно)**.

## 30-дневная бесплатная e-виза

- Срок пребывания — **30 дней** с даты первого въезда.
- **Двукратная** (два въезда в период действия).
- Въезд разрешён в течение **120 дней** с даты выдачи визы.
- Оформление онлайн, обработка обычно **до 72 часов**.

## Многократные визы

Упрощение не распространяется на **многократные** визы: например, 5-летняя туристическая виза платная —
её стоимость выросла и составляет около **120 USD** (сверяйте актуальную сумму на портале).

## Документы

- Загранпаспорт (минимум 6 месяцев действия, чистые страницы).
- Цифровое фото и скан страницы паспорта для загрузки.
- Данные о маршруте/проживании; обратный билет.

## Частые вопросы

- **e-Visa оформляется только онлайн** на официальном портале — остерегайтесь платных сайтов-посредников.
- Въезд по e-Visa — только через определённые аэропорты и морпорты (проверяйте список).
- Данные заявки должны точно совпадать с паспортом; въезд — в пределах 120-дневного окна.
