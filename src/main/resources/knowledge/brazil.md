# Бразилия — безвизовый режим

> Справочный материал для консультаций. Правила и сроки меняются — сверяйте на сайте МИД/полиции Бразилии
> перед поездкой. Данные на июль 2026.

## Визовый режим для граждан РФ

Граждане РФ въезжают в Бразилию **без визы** для туризма и коротких визитов — пребывание **до 90 дней**
(с возможным продлением ещё до 90 дней в пределах 180 дней в году, по правилам федеральной полиции).

## Документы к въезду

- Загранпаспорт (обычно требуют запас действия 6 месяцев).
- Обратный/транзитный билет.
- Подтверждение проживания и достаточных средств.
- Иногда — подтверждение вакцинации от жёлтой лихорадки (для отдельных регионов/маршрутов; сверяйте).

## Продление и другие цели

Продление туристического срока оформляется в **федеральной полиции** Бразилии. Для работы, учёбы и долгого
пребывания — соответствующие визы, оформляемые заранее.

## Нюансы

- Соблюдайте лимит **90 + 90 дней в году** — превышение ведёт к штрафам.
- Для въезда — только загранпаспорт с достаточным сроком действия.
- Проверяйте требования по жёлтой лихорадке для конкретных штатов и стыковок.

## Частые вопросы

- **Нужна ли виза?** Нет для туризма до 90 дней.
- Можно ли продлить? Да, через федеральную полицию, в пределах годового лимита.
- Для работы виза обязательна.
