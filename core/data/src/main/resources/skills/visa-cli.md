# SKILL: visa-cli (локальный помощник «Визового специалиста»)

Это навык работы с **локальным CLI** `visa-cli`. В отличие от MCP-инструментов (их схемы грузятся в каждый
запрос), эта инструкция подключается **по требованию** — только когда навык включён и реально нужен.

## Когда применять
Используй `visa-cli`, когда задача про **локальные данные пользователя**, которые не нужно искать в интернете:
- посмотреть, какие документы пользователь приложил по ТЕКУЩЕМУ делу.

## Как вызвать
Чтобы выполнить команду, выведи ОТДЕЛЬНОЙ строкой:

```
[CLI] visa-cli <команда> [опции]
```

Система выполнит её и вернёт результат строкой `[CLI_RESULT] …`. После этого дай человеку обычный ответ,
опираясь на полученные данные. Можно вызвать несколько команд по очереди (вывод одной — вход рассуждения для
следующей). Аккаунт и текущий диалог подставляются автоматически — `--account` и `--conv` указывать не нужно.

## Доступные команды
- `visa-cli docs` — список документов текущего дела (имя + размер).
- `visa-cli docs check` — содержимое этих документов (извлечённый текст PDF) для СВЕРКИ данных.
- `visa-cli version` — версия CLI.

## Скоуп: только текущее дело
`docs` и `docs check` показывают файлы, приложенные **в этом диалоге**. Документы прошлых поездок лежат в
архиве аккаунта и в выдачу НЕ попадают. Если в выводе всё же стоит пометка «АРХИВ аккаунта» — это файлы
других дел: не сверяй их с текущей поездкой и не объявляй из-за них пакет невалидным.

## Правила доказательства (нарушать нельзя)
1. **Имя файла — не доказательство.** ФИО, страну, даты и номера бери ТОЛЬКО из извлечённого текста.
   `PASSPORT RUS IVAN.pdf` не значит, что внутри Иван, и не значит, что заявителей стало больше.
2. **Каждое утверждение — с цитатой.** Пишешь «бронь на Лондон» — приведи фрагмент текста, откуда это видно.
   Нет цитаты — нет утверждения.
3. **Текст не извлёкся (скан) → «не проверено».** Это не «плохой документ» и не «хороший»: по такому файлу
   выводов о владельце и годности не делаешь, а честно говоришь, что автоматически проверить не вышло.
4. **Не считай людей по числу файлов.** Один заявитель прикладывает и паспорт, и справку, и бронь.
5. **Не пересказывай свои прошлые сообщения.** Каждая проверка — заново по свежему `[CLI_RESULT]`.
6. **Даты бери из полей документа** (check-in/check-out, срок действия, период страхования), а не из
   штампа печати страницы в шапке — это дата, когда файл распечатали, и к поездке она отношения не имеет.

## Что сверять
По извлечённому тексту сопоставь с досье кейса (`[STATE]`):
- владелец: на ОДНО ли лицо оформлены документы (совпадают ли ФИО, в т.ч. латиница загранпаспорта);
- страна: совпадает ли страна в брони/анкете со страной поездки;
- даты: покрывают ли бронь/билеты/страховка даты поездки.
Расхождение, подтверждённое цитатой, — предупреди (⚠️) и НЕ принимай пакет как валидный. Всё, что проверить
не удалось, перечисли отдельным списком «не проверено».

## Прочее
- Вызывай ТОЛЬКО `visa-cli` (других команд нет; произвольный shell запрещён).
- Если по выводу видно, что документов нет, — так и скажи и подскажи, что приложить.
