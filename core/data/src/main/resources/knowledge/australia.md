# Австралия — гостевая виза (Visitor visa 600)

> Справочный материал для консультаций. Правила и сборы меняются — сверяйте на официальном сайте
> immi.homeaffairs.gov.au. Данные на июль 2026.

## Визовый режим для граждан РФ

Гражданам РФ **нужна виза** в Австралию. Упрощённые электронные разрешения (ETA/eVisitor) гражданам РФ
**недоступны** — оформляют **гостевую визу Visitor visa (subclass 600)** полностью онлайн через аккаунт
ImmiAccount.

## Как оформляют

- Регистрация в **ImmiAccount**, онлайн-анкета, загрузка документов.
- Возможен запрос биометрии и медосмотра.
- Решение приходит по email; виза электронная (привязана к паспорту).

## Пакет документов

- Загранпаспорт.
- Подтверждение цели поездки, маршрут, брони жилья и билетов.
- Финансовые гарантии (выписки, справка с работы), связи с родиной.
- При гостевом визите — приглашение и документы принимающей стороны.

## Сборы и сроки

- Визовый сбор Visitor 600 — платный (сверяйте актуальную сумму на сайте).
- Рассмотрение может занять от нескольких недель — подавайте заранее.

## Частые вопросы

- **ETA/eVisitor не для РФ** — только Visitor visa 600.
- Возможны разные потоки (туризм, гостевой, бизнес) в рамках subclass 600.
- Слабые связи с родиной и неубедительные финансы — частые причины отказа.
