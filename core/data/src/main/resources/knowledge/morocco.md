# Марокко — безвизовый режим

> Справочный материал для консультаций. Правила меняются — сверяйте на сайте посольства Марокко и портале
> e-Visa. Данные на июль 2026.

## Визовый режим для граждан РФ

Граждане РФ въезжают в Марокко **без визы** для туризма — пребывание **до 90 дней**. Для отдельных целей и
долгого пребывания оформляют визу; параллельно у Марокко есть система **e-Visa** для ряда случаев/стран —
сверяйте применимость.

## Документы к въезду

- Загранпаспорт (обычно требуют запас действия 6 месяцев).
- Обратный/транзитный билет.
- Подтверждение проживания и достаточных средств (могут спросить).

## Нюансы

- На въезде заполняют миграционную карточку; сохраняйте штамп/карту до выезда.
- Продление свыше 90 дней оформляется в местной полиции по делам иностранцев.
- Российские карты за рубежом не работают — планируйте наличные.

## Частые вопросы

- **Нужна ли виза?** Нет для туризма до 90 дней.
- Как продлить? Через местные органы, заранее.
- Для работы/учёбы — отдельные визы и разрешения.
