# Антипаттерны

1. **Всё в один промпт** (профиль + история + факты + … = десятки k токенов) → модель теряет фокус,
   ответ деградирует.
   → Разделяй на слои, инжектируй только нужное для текущего шага (режим «3 слоя», `MEMORY_MODEL.md`).

2. **Решения за LLM в тексте** (переходы состояния / правила «просьбой» в промпте) → LLM услужливо
   согласится на что угодно.
   → Логику переходов и проверку инвариантов держать в **коде** (`require` / `check`), не в промпте (`STATE_MACHINE.md`).

3. **Постоянная суммаризация** → теряются детали.
   → Сворачивать историю редко; для новой темы — новый диалог (чистое окно лучше «болота» из всего подряд).

4. **Молчаливое проглатывание ошибок API** (показать «пустой ответ» вместо причины).
   → Поднимать понятную ошибку (статус + текст), как в `data/LlmClient.kt` (например, 429 rate-limit).

5. **Обязательный фасет (страна, версия, клиент) — «мягким» словом в тексте запроса RAG.** Отбор кандидатов
   идёт ДО реранка и по всему корпусу: документ, не попавший в пул, вернуть уже нечем — ни реранком (он
   работает только внутри пула), ни порогом (он режет снизу, а не по фасету). Реальный случай: на кейсе
   «Испания, туризм» выдачу занимал `japan.md` (у него «туризм» в H1, а `ContextualChunker` вклеивает
   заголовок в каждый чанк), лучший `spain.md` стоял 45-м из 318 — агент отвечал по правилам Японии.
   → Фасет применять к **множеству кандидатов** (`CountryScope` + `allow`-предикат в `KnowledgeIndex.search`),
   а не к строке запроса. Плюс два следствия: **чёрный список** (режем только чужое страновое, агностичное и
   пользовательское видно по умолчанию) и **якорь** — если у фасета есть свой документ, гарантируем из него
   фрагмент, иначе тонкий документ проигрывает общим по «типовым» словам. Проверка: `gradlew runRagCountryCheck`.

6. **Ответ по данным «похожей» сущности вместо честного отказа.** Если по стране кейса документа нет,
   пересказать соседнюю — худший исход для визового домена: ответ правдоподобен и непроверяем.
   → Явное предупреждение в блоке `[БАЗА ЗНАНИЙ]` + деградация на `[СПРАВКА ПО ВИЗЕ]`/MCP (`TaskOrchestrator.ragContext`).
